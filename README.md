# xmip-core-message-csv

CSV shape: RFC 4180 records as numbered parts with the header row named when there is one, no announced type. A technology of [xmip-core-message](https://github.com/IlleNilsson/xmip-core-message).

## Toolchain

`rust-toolchain.toml` pins the toolchain for the whole estate. Do not change it
here.

## Verification

The included workflow is manual-only and calls the versioned shared workflow at
`IlleNilsson/.github@v1`.
